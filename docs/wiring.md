# Pinbelegung ESP32

| Komponente | ESP32 Pin | Anmerkung |
| :--- | :--- | :--- |
| Kapazitiver Feuchtigkeitssensor (AOUT) | GPIO34 | Analoger Eingang (ADC) |
| Feuchtigkeitssensor VCC / GND | 3.3V / GND | Stromversorgung |
| DHT22 Temperatursensor (DATA) | GPIO4 | Digitaler Eingang |
| DHT22 VCC / GND | 3.3V / GND | Stromversorgung |
| Relais Steuereingang (IN) | GPIO16 | Schaltet Pumpe ein/aus |
| Relais VCC / GND | 5V (VIN) / GND | Externe Versorgung je nach Relais |
